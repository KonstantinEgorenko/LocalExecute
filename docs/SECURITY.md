# Security and trust model

Native verification runs trusted code on the host. Scope guards, Git isolation and Windows Job ownership are not an OS sandbox against malicious generated code. Use controlled first-party targets. Docker primitives are separate and not universal execution routing.

Do not place secrets in model context or publish raw experiment state. Candidate hashes, provenance, lease ownership and failed deterministic verification remain acceptance authorities. Missing mandatory private V1 evaluator fails closed. Optional posthoc scores cannot upgrade Mission state. Model weights/services have separate licenses and setup requirements.
